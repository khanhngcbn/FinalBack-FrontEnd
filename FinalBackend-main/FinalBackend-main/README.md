# 🌙 BlueMoon Management Website

This is the **backend** of the BlueMoon management system, built with **Spring Boot**. The frontend is developed separately and can be built/deployed independently.

---

## 📦 Tech Stack

- **Backend:** Spring Boot (Java)
- **Frontend:** Separate module (see below)

---

## 🚀 How to Run

### 1. Clone the project

```bash
git clone https://github.com/tranthai189765/BlueMoon.git
cd BlueMoon
```

### 2. Build the backend

Using Maven Wrapper:

```bash
./mvnw clean install
```

Or with Maven:

```bash
mvn clean install
```

### 3. Run the backend

```bash
./mvnw spring-boot:run
```

Or run directly from your IDE (e.g. IntelliJ, Eclipse) using the `main` method in the `com.bluemoon` package.
